# C-Language Compiler Tokenizer & Symbol Table Generator using FLEX

A complete, modern desktop application for lexical analysis of C-Language source code, built around an authoritative **FLEX (Fast Lexical Analyzer)** tokenization engine paired with a rich **PySide6** desktop graphical interface.

---

## 1. Project Purpose

In compiler construction, **lexical analysis (tokenization)** is the first and foundational phase of the compiler pipeline. It scans the raw characters of a source program and converts them into a sequence of meaningful lexical tokens (lexemes paired with token classes), identifies lexical errors, and constructs the initial **Symbol Table**.

This project provides an academic and developer-grade GUI compiler tool that bridges low-level C FLEX tooling with an interactive desktop interface, allowing students, instructors, and compiler engineers to:
- Tokenize multi-line C code constructs in real time.
- Select from **15 built-in C test cases** covering arithmetic, conditionals, loops, functions, pointers, preprocessors, and lexical error diagnostics.
- View the complete ordered token stream with source line numbers, categories, and color-coded badges.
- Inspect categorized breakdowns: **Keywords**, **Identifiers**, **Literals / Constants**, **Operators**, **Punctuators**, **Comments**, and **Preprocessor Directives**.
- Explore a consolidated **Compiler Symbol Table** listing unique lexemes, their token types, occurrences, and line numbers.
- Detect, highlight, and isolate lexical errors (unrecognized characters) with precise line diagnostics.
- Export complete compiler tokenization and symbol table reports to text files.

## 3. Supported C Token Categories

| Category | Token Types | FLEX Pattern / Examples | Description |
| :--- | :--- | :--- | :--- |
| **Keywords** | `KEYWORD` | `int`, `float`, `char`, `double`, `void`, `if`, `else`, `for`, `while`, `do`, `switch`, `case`, `default`, `break`, `continue`, `return`, `struct`, `sizeof`... | 32 C reserved language keywords |
| **Identifiers** | `IDENTIFIER` | `[a-zA-Z_][a-zA-Z0-9_]*` (`main`, `count`, `ans`, `ptr`...) | Variable, function, and struct names |
| **Constants & Literals** | `INTEGER`, `FLOAT`, `STRING_LITERAL`, `CHAR_LITERAL` | `10`, `0x1F`, `3.14`, `"hello\n"`, `'A'` | Whole numbers, floating-point decimals, strings, chars |
| **Arithmetic Operators** | `PLUS`, `MINUS`, `MULTIPLY`, `DIVIDE`, `MODULO`, `POWER` | `+`, `-`, `*`, `/`, `%`, `^` | Standard mathematical arithmetic operations |
| **Assignment Operators** | `ASSIGN`, `ADD_ASSIGN`, `SUB_ASSIGN`, `MUL_ASSIGN`, `DIV_ASSIGN`, `MOD_ASSIGN` | `=`, `+=`, `-=`, `*=`, `/=`, `%=` | Simple and compound assignment operators |
| **Increment / Decrement** | `INC_OP`, `DEC_OP` | `++`, `--` | Pre/post increment and decrement |
| **Relational Operators** | `LT_OP`, `GT_OP`, `LE_OP`, `GE_OP`, `EQ_OP`, `NE_OP` | `<`, `>`, `<=`, `>=`, `==`, `!=` | Comparisons and equality tests |
| **Logical Operators** | `LOGICAL_AND`, `LOGICAL_OR`, `LOGICAL_NOT` | `&&`, `\|\|`, `!` | Boolean logic operators |
| **Bitwise Operators** | `BIT_AND`, `BIT_OR`, `BIT_XOR`, `BIT_NOT`, `LEFT_SHIFT`, `RIGHT_SHIFT` | `&`, `\|`, `^`, `~`, `<<`, `>>` | Bitwise manipulation and shift operators |
| **Member & Pointer** | `DOT`, `ARROW` | `.`, `->` | Struct member and pointer member access |
| **Punctuators** | `LPAREN`, `RPAREN`, `LBRACE`, `RBRACE`, `LBRACKET`, `RBRACKET`, `SEMICOLON`, `COMMA` | `(`, `)`, `{`, `}`, `[`, `]`, `;`, `,` | Delimiters, statement terminators, grouping |
| **Preprocessor** | `PREPROCESSOR`, `HEADER_FILE` | `#include`, `#define`, `<stdio.h>` | Directives and standard include headers |
| **Comments** | `COMMENT` | `// ...`, `/* ... */` | Single-line and multi-line comments |
| **Lexical Errors** | `ERROR` | `.` (fallback) e.g., `@`, `$`, `` ` `` | Unrecognized or illegal source characters |

## 4. Built-in Test Cases

The application includes **15 built-in test case presets** ready to load and tokenize with a single click:

1. **Arithmetic Operators & Expressions:** Addition, subtraction, multiplication, division, modulo, and compound assignments (`+=`, `*=`).
2. **If - Else Conditional Statements:** Nested branching, comparison operators (`>=`, `<`, `==`), and logical operators (`&&`).
3. **Do - While Loop Construct:** Post-condition iteration, block scopes, and increment operator (`count++`).
4. **For Loop with Step & Accumulation:** Multi-part `for (int i = 1; i <= n; i++)` statement structure.
5. **Function Declaration & Invocation:** Function signatures, parameters, return types, and function calls with arguments.
6. **Switch - Case Multi-way Branching:** `switch`, `case`, `default`, `break`, and integer labels.
7. **Nested Loops (Pattern Generation):** Two-dimensional nested `for` loops generating matrix patterns.
8. **Struct Definition & Pointer Member Access:** `struct` keyword, dot operator (`.`), arrow operator (`->`), and address-of (`&`).
9. **Preprocessor Directives & Macro Constants:** `#include <stdio.h>`, `#define MAX_BUFFER`, and `const` keyword.
10. **While Loop with Break and Continue:** Control transfer statements inside a `while` loop.
11. **Array Operations & Sizeof Operator:** Bracket indexing (`numbers[5]`), array initialization, and `sizeof()` operator.
12. **Ternary Operator & Complex Logical Expressions:** `?:` conditional operator and compound boolean logic (`&&`, `||`, `!`).
13. **⚠ Lexical Errors Demonstration:** Contains illegal characters (`@`, `$`, `` ` ``) to demonstrate error detection and line diagnostic reporting.
14. **Comments (Single-Line & Multi-Line):** Single-line `//` comments, multi-line `/* ... */` blocks, and inline annotations.
15. **Complete Comprehensive Program (All Constructs):** A complete C program with includes, macros, functions, loops, branching, and formatted console output.

## 5. UI Features & Layout

- **Multi-line Monospace C Code Editor:** Formatted code input area with auto-sizing and placeholder guidance.
- **Ordered Token Stream (Left Panel):**
  - Displays token index (`#`), source line number (`Line`), category badge, token type badge, and monospace lexeme.
  - Interactive live search filter box for filtering tokens in real-time.
- **Navigator Tabs (Right Panel):**
  - 📊 **Statistics:** Visual grid cards for Total Tokens, Keywords, Identifiers, Literals, Operators, Punctuators, Comments, Preprocessor, and Errors.
  - 📋 **Final Symbol Table:** Consolidated overview table of all unique lexemes, their categories, token types, frequency counts, and all line numbers where they appear.
  - 🔑 **Keywords Tab:** Filtered view of all keywords and their line occurrences.
  - 📛 **Identifiers Tab:** Filtered view of all identifier names and line occurrences.
  - 🔢 **Literals Tab:** Filtered view of numeric, character, and string constants.
  - ⚙️ **Operators Tab:** Filtered view of all operator symbols.
  - ⚠ **Lexical Errors Tab:** Dedicated error alert banner and detailed error diagnostic table.
  - 📖 **Token Reference Tab:** Quick-reference cheat sheet of compiler lexical rules for demonstrations and viva presentations.
- **File Operations:**
  - **Open File:** Load `.c`, `.h`, or `.txt` files directly into the workspace.
  - **Save Results:** Export complete structured reports (input code, token stream, statistics, error log, and symbol table) to `.txt`.
  - **Clear:** Reset editor and all tables with one click.

## 6. How to Run

### Prerequisites
- Python 3.10+
- PySide6
- pytest (for automated tests)

Install dependencies:
```bash
pip install -r requirements.txt
```

### Launch the Application
Run from the project root:
```bash
python ui/main.py
```
Or as a Python module:
```bash
python -m ui.main
```

### Run Automated Unit Tests
```bash
pytest tests/test_tokenizer_unit.py -v
```

## 7. Recompiling the FLEX Engine (Optional)

If modifying `lexer.l`, regenerate and compile the binary:
```bash
flex lexer.l
gcc lex.yy.c -o lexer.exe
```
