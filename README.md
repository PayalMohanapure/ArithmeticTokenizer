# Arithmetic Expression Tokenizer using FLEX

A complete, modern desktop application for lexical analysis of arithmetic expressions, built around an authoritative **FLEX (Fast Lexical Analyzer)** tokenizer.

---

## 1. Project Purpose

In compiler construction and systems programming, **lexical analysis (tokenization)** is the critical initial phase that translates an incoming stream of raw characters into structured lexical tokens (lexemes paired with token classes). 

This project provides a complete, modern desktop interface for an existing C-based FLEX lexical analyzer. The application bridges low-level compiler tooling with an intuitive visual workspace, allowing students, instructors, and developers to:
- Interactively input and test arithmetic expressions.
- Inspect exact token sequences generated by the compiled FLEX engine.
- Identify lexical errors and invalid characters in real-time.
- View categorized token statistics (Identifiers, Numbers, Operators, Parentheses).
- Load expressions from text files and export complete formatted tokenization reports.

## 2. System Architecture

The project maintains a strict separation of concerns between the **lexical analysis engine** and the **presentation interface**:

```
ArithmeticTokenizer/
│
├── lexer.l              # FLEX source file containing regular expression rules & actions
├── lex.yy.c             # C source code generated by FLEX compiler
├── lexer.exe            # Authoritative compiled native binary (Tokenization Engine)
├── sample.txt           # Sample input expression
├── tokens_output.txt    # Canonical reference output from the lexer
├── README.md            # Complete project documentation
│
└── ui/
    ├── __init__.py      # Package marker
    ├── main.py          # Application entry point & Qt setup
    ├── main_window.py   # Modern PySide6 desktop GUI & workspace
    ├── lexer_runner.py  # Subprocess executor (pipes stdin/stdout safely)
    ├── token_parser.py  # Parses raw FLEX output into structured Token models
    ├── statistics.py    # Categorization and report formatting logic
    └── styles.py        # Professional slate dark theme styling & typography
```

> **Note:** The desktop UI does not re-implement tokenization in Python. All token identification is performed strictly by executing `lexer.exe`.

## 3. Supported Tokens

The FLEX lexer defines regular expressions for the following token categories:

| Token Type | Category | Pattern / Rule | Description |
| :--- | :--- | :--- | :--- |
| `IDENTIFIER` | Variables | `[a-zA-Z_][a-zA-Z0-9_]*` | Variable names and identifiers |
| `INTEGER` | Numbers | `[0-9]+` | Whole integer numbers |
| `FLOAT` | Numbers | `[0-9]+\.[0-9]+` | Floating-point decimal numbers |
| `PLUS` | Operator | `+` | Addition operator |
| `MINUS` | Operator | `-` | Subtraction operator |
| `MULTIPLY` | Operator | `*` | Multiplication operator |
| `DIVIDE` | Operator | `/` | Division operator |
| `MODULO` | Operator | `%` | Remainder / Modulo operator |
| `POWER` | Operator | `^` | Exponentiation operator |
| `LPAREN` | Grouping | `(` | Left grouping parenthesis |
| `RPAREN` | Grouping | `)` | Right grouping parenthesis |
| `ASSIGN` | Operator | `=` | Assignment operator |
| `ERROR` | Lexical Error | `.` (fallback) | Any invalid or unrecognized character |

Whitespace characters (spaces and tabs `[ \t]+`) and newlines (`\n`) are ignored as separators.

## 4. Features & User Interface

1. **Multiline Expression Editor:** Comfortable monospace code input area with placeholder guidance and clipboard paste support.
2. **Sample Expression Presets:** Instant loading of 8 representative test expressions covering basic math, variables, floating-point numbers, nested parentheses, powers, modulos, and invalid characters.
3. **Structured Token Table:** Displays token sequence numbers (`#`), monospace lexemes, and color-coded semantic badges for token classes.
4. **Live Statistics Grid:** Automatically counts and presents:
   - Total Tokens
   - Identifiers
   - Numbers (`INTEGER` + `FLOAT`)
   - Operators (`+`, `-`, `*`, `/`, `%`, `^`, `=`)
   - Parentheses (`(`, `)`)
   - Errors
5. **Dedicated Error Panel:** Distinct alert card showing `✓ No lexical errors detected` or highlighting detected invalid characters (e.g. `@  →  Invalid character`).
6. **Token Legend Reference:** Quick reference card detailing supported rules for project demonstrations and viva examinations.
7. **File Operations:**
   - **Open File:** Load any `.txt` expression file into the workspace without auto-executing.
   - **Save Results:** Export a complete, formatted `.txt` report containing the input, token sequence, statistics, and error log.
   - **Clear:** Reset editor, table, statistics, and error status in one click.

## 5. Getting Started & How to Run

### Prerequisites
- Python 3.10 or later
- PySide6 (or PySide6-Essentials)

Install requirements:
```bash
pip install -r requirements.txt
```
*(Or `pip install PySide6-Essentials` if only running the GUI)*


### Launching the Application
Launch the desktop application directly from the repository root:
```bash
python ui/main.py
```
Or run as a module:
```bash
python -m ui.main
```

## 6. Example Usage & Output

### Example Input
```text
result = 12.5 + 3.14 * (x - 2)
```

### Generated Token Sequence
```text
1. result       IDENTIFIER
2. =            ASSIGN
3. 12.5         FLOAT
4. +            PLUS
5. 3.14         FLOAT
6. *            MULTIPLY
7. (            LPAREN
8. x            IDENTIFIER
9. -            MINUS
10. 2           INTEGER
11. )           RPAREN
```

### Computed Statistics
```text
Total Tokens:  11
Identifiers:    2
Numbers:        3
Operators:      4
Parentheses:    2
Errors:         0
```

### Error Handling Example
Input:
```text
x = 10 @ 20
```
Output:
- Table Row 4: Lexeme `@` with badge `ERROR`
- Error Panel: `⚠ Detected 1 lexical error(s): • @ → Invalid character (Token #4)`
- Statistics: `Total Tokens: 4`, `Errors: 1`
